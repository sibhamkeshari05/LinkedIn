💼 LinkedIn Clone – MERN Stack

A full-stack professional networking platform inspired by LinkedIn, where users can connect with other professionals, share posts, interact with content, and build their professional network.

🚀 Live Demo

- Frontend: https://linkedin-frontend-8xbx.onrender.com
- Backend: https://linkedin-backend-kcwx.onrender.com

✨ Features

- 🔐 User Authentication (Signup & Login)
- 👤 User Profile Creation & Editing
- 📝 Create, Like & Unlike Posts
- 💬 Comment on Posts
- 🔍 Search Other Users
- 🤝 Send, Accept & Manage Connections
- 🔔 Real-time Notifications
- 💬 Real-time Chat Functionality
- 👥 Suggested Users
- 🖼️ Profile Picture & Cover Image Upload

🛠️ Tech Stack

Frontend:

- React.js
- Tailwind CSS
- Axios
- React Router

Backend:

- Node.js
- Express.js
- MongoDB
- Mongoose
- Socket.IO
- JWT Authentication

Deployment:

- Render
- GitHub

⚙️ Installation & Setup

1. Clone the repository:

git clone https://github.com/sibhamkeshari05/LinkedIn.git

2. Install frontend dependencies:

cd frontend
npm install

3. Install backend dependencies:

cd ../backend
npm install

4. Configure environment variables in the backend ".env" file.

5. Start the backend:

npm run dev

6. Start the frontend in another terminal:

cd frontend
npm run dev
